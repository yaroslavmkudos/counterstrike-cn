# Components

Browse all available CS 1.6 themed components. Each component is copy-paste ready and built with TypeScript, Tailwind CSS, and Radix UI primitives.

## Core UI

| Component | Description |
|-----------|-------------|
| [Button](/docs/components/button) | VGUI-style buttons with 3D beveled borders |
| [Input](/docs/components/input) | Text input with inset bevel styling |
| [Card](/docs/components/card) | Panel container with header/content/footer |
| [Dialog](/docs/components/dialog) | Modal dialog with VGUI window chrome |
| [Badge](/docs/components/badge) | Team and status badges |
| [Progress Bar](/docs/components/progress-bar) | Loading/download progress indicator |

## Game UI

| Component | Description |
|-----------|-------------|
| [HUD](/docs/components/hud) | Health, Armor, Ammo, Money, Timer displays |
| [Scoreboard](/docs/components/scoreboard) | TAB-style scoreboard with team sections |
| [Buy Menu](/docs/components/buy-menu) | Full buy menu with categories and pricing |
| [Kill Feed](/docs/components/kill-feed) | Top-right kill notification feed |
| [Radar](/docs/components/radar) | Circular minimap with player dots |
| [Chat](/docs/components/chat) | In-game chat with team colors |
